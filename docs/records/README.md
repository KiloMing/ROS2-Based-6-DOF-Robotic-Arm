# 验收与故障记录

当前 M0–M7 均未验收。基本驱动完成是用户提供的现状，不是本次远程实测结论。

每次验收新建记录，填写：阶段、日期、执行者、Git SHA、硬件/固件/软件版本、前置检查、预先确定的阈值及理由、步骤、样本数、原始数据位置、统计结果、通过/失败、未解决项、下一步。空字段不能算通过。

标定表至少包含：关节名、执行器 ID、型号/模式、轴方向、零位、原始位置与实测角度、映射、软限位、重复性、测量工具及日期。不要先填猜测值。

故障记录使用 `fault-编号.md`：现象与预期、最小复现、错误日志、影响范围、假设、单变量实验、结果、根因、修复提交、回归证据。未定位根因写“待查”，不要写成“已解决”。失败后标记阶段未通过，退回路线指定节点；恢复后复测本阶段和受影响的后续阶段。
