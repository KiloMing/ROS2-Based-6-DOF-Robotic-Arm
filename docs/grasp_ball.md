# 单个静止网球抓取实验

入口：`tools/vision/grasp_ball.py`。复用当前 110 mm 轴线上 TCP、相机球面坐标和 MoveIt 服务。004 保持开始角度，005 张合。原 `contact_moveit.py` 仍可单独用于靠近。

## 流程

1. 检查三个控制器 active、模型 TCP 为 `[0,0,0.110]`，采集五次新鲜球面坐标及其时间对应的相机 TF。
2. 近似球心 = 球面 ROI 点 + 沿相机视线的半径。要求五帧球心稳定在 5 mm 内。这不是点云球面拟合，ROI 不在球正面中心时会有偏差。
3. 在球心对应的机械臂径向平面，尝试当前俯仰和 100°、90°、110°、120° 俯仰。004 固定；使用原 `arm` 组的完整位姿逆解，将 TCP 转换至其 `tool0` 求解，避免位置逆解进入时改变朝向。
4. 一次性验证三段：当前姿态到预抓取点、直线进入、竖直抬起。每条路径都检查关节范围和 004，末两段必须完整，碰撞检查保留。预抓取距离默认球面前 50 mm。
5. 默认到此结束，只保存规划。`--execute` 才会张爪，执行预抓取，重新观测球心，重新规划并执行进入，闭爪，按实际反馈重新规划并执行上抬。
6. 抬起默认 30 mm 后保持，不自动松开，也不继续搬运。状态为 `completed_unverified`，`grasp_confirmed` 始终为 false：当前没有力传感器或可信的视觉抓取成功检测。

程序估计的球心应对齐夹指内部的夹持中心，而不是指尖。若插入深度为 d，目标指尖平面中心 = 球心 + 夹爪前向轴 × d。

## 三个必须提供的尺寸（单位米）

- `--ball-diameter`：实际球直径。
- `--max-opening`：最大张开时两夹指内侧的实际距离。
- `--insertion`：夹指最前端到期望夹持中心的深度。

“差不多一样大”表示余量很小，并不意味着实际开口就是驱动表中的 60 mm。驱动目前把 raw 1100 映射为单侧 30 mm；本程序将实测最大开口线性映射至模型的单侧最大位置。这仍是近似标定，不能替代实测开度曲线。开口等于球径时允许规划，但没有余量，不能保证实物能顺利进入。

`--compression` 默认 0.002 m，闭爪名义开口为球径减去该值，不是直接关闭到零，也不是力控制。控制器报成功后仍核对实际关节位置；偏离目标超过单侧 2 mm 则中止，不自动抬起。位置停止/到位都不能证明夹住了球。

## 启动依赖

先运行实物 MoveIt、相机 TF、识别和坐标转换，沿用 `docs/vision_arm_operations.md` 的启动流程。必须加载修正后的 110 mm 模型。不要同时启动第二套实物控制器，也不要同时运行其他机械臂运动脚本。

每个终端先执行：

```bash
source /opt/ros/jazzy/setup.bash
source /home/kiloming/ROS2-Based-6-DOF-Robotic-Arm/arm_ws/install/setup.bash
```

以下数值是隔离模拟测试用例，**不是用户实物尺寸的确认值**：

```bash
# 只规划，不发送运动；替换三个尺寸为实际测量值
python3 /home/kiloming/ROS2-Based-6-DOF-Robotic-Arm/tools/vision/grasp_ball.py \
  --ball-diameter 0.060 --max-opening 0.060 --insertion 0.020
```

实物尺寸核对并检查规划结果后，在同一条命令末尾添加 `--execute` 即执行一次。可用 `--lift 0.03`、`--clearance 0.05`、`--table-z 0.0` 调整抬起距离、预抓取距离和桌面高度。

默认报告 `/tmp/grasp_ball_report.json`，包含阶段、尺寸、球心估计、固定腕角、倾角搜索失败原因、路径及夹爪反馈。任一阶段失败不自动重试，未完成动作会请求取消。

## 当前范围与验证

- 桌面和模型碰撞检测有效，但尚未把球加入碰撞场景或设置附着物；不能据此执行带球绕障碍搬运。
- 抓取后没有自动识别滑落。3 cm 提起只是实验动作，不是抓取成功证明。
- 近似夹爪内部几何、舵机零位和相机外参仍影响实物精度。不能通过放大容差修复这些几何误差。
- 回归测试覆盖球面/球心/指尖偏移、开口映射、非法尺寸、内部轨迹点、失败动作及超时取消句柄保留。

2026-11-19 隔离模拟验证：ROS_DOMAIN_ID=88、GenericSystem、real_joint_limits，球面目标 [0.20,0,0.15] m，相机原点 [0.10,0,0.25] m；测试球径和最大开口均 60 mm、插入深度 20 mm。三段规划及张爪、预抓取、进入、闭爪、抬起动作全部完成，报告状态 completed_unverified，grasp_confirmed=false。模拟没有球体接触动力学，结果只验证流程和接口。21 项回归测试通过。

两次实物尝试均未得到完整路径，未发送抓取动作；五个候选俯仰方向出现 IK failed: -31。两次估计球心分别约为 [0.2788, 0.0033, -0.0044] m 与 [0.3113, 0.0760, -0.0057] m，而程序桌面设为 base_link 下 z=0。球心高度与该桌面假设不一致，需要核对相机外参、球面到球心近似和真实桌面高度。此证据不能单独证明某一项是唯一失败原因。

当前结论：模拟流程通过，实物抓取未验证成功。之前的靠近程序使用球面位置和位置逆解；抓取程序增加球心偏移、完整姿态、进入和抬起路径，因此靠近成功不等于抓取路径可达。
